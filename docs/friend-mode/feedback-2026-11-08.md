# Feedback round, 2026-11-08

Ten items from a co-op playthrough (Britain). On `feature/friend-mode`, not
the battle-orders branch. Causes found in the code and the game's scripts
(`tools/friend-mode/ucread.py`). **Built 2026-11-08, not yet tested in
play: 1, 3, 4, 7, 8, 9, 10** (protocol 40; see "As built" at the end).
2, 5 and 6 wait for a look in play.

Order of work: the sure causes first (1, 4, 7, 8, 9), then the NPC sync

(2, 5, 6).

## Causes found, with the fix

1. **Pocketwatch shows nothing on a guest.** The watch (159) is on the
   guest list as "use on self", so the host runs its script (0x9F), which
   does `item_say` on the watch. The watch is in the companion's pack, and
   `Friend_mode_note_speech` drops object speech whose outermost thing is
   an actor, so the text only shows on the host, if at all.
   **Fix:** the script only reads `game_hour`/`game_minute`, and the
   guest's clock is the host's, so move 159 to
   `Friend_mode_guest_local_shape` (like the sundial): the guest runs it on
   its own copy, and `in_gump_mode` puts the text over the open pack as in
   Exult. Also, for anything else that speaks from inside a pack: send it
   as the carrier's speech (NPC number) instead of dropping it.

4. **Spell bar (quick slots) empty after Journey Onward.** The bar is
   read from `gamedat/friendbar.dat` by `Friend_class_world_loaded`, called
   from `Game_window::read()` (Load). Journey Onward starts in exult.cc
   with `init_files` / `read_gwin` / `setup_game` and never calls `read()`,
   so the bar stays empty (and the cooldown resets there are skipped too).
   **Fix:** call `Friend_mode_note_world_loaded` after that `setup_game`
   (or move the call into `setup_game`, which `read()` also uses).

7. **Strength tester, its plaques, the sword in the stone's plaque.**
   - Strength tester (743, script 0x2E7) is in the Usable group but not on
     any guest list, so a guest gets "The Avatar must do this". Its script
     walks the user there (`fn 0828`), then reads the user's strength
     (`get_npc_prop(-356, 0)`), swings, and pays a prize with
     `add_party_items`. Our walker substitution already turns -356 into the
     guest's companion while the host runs it for the guest, and carries
     over to the delayed step. **Fix:** add 743 to
     `Friend_mode_guest_usable_shape` (host runs it, companion walks and
     swings, its own strength counts). Check that its gold cost comes from
     the party.
   - Plaques (820, script 0x334) aren't on `Friend_mode_guest_local_shape`
     (signs 379 and tombstones 715 are). 0x334 is not a plain read: by
     quality it is also Penumbra's plaque (removes things, kills an NPC) and
     others. **Fix:** let the guest read a plaque locally only for the
     qualities whose branch just calls `display_runes`; the rest stay the
     Avatar's. To do: list 0x334's branches by quality.

8. **Bale of wool: use it, then pick the spinning wheel.** The bale (653,
   script 0x28D) takes it into the user's pack, then 0x62D asks
   `click_on_item` and wants the spinning wheel (651). The spindle of
   thread (654, 0x28E then 0x62E) is the same with the loom (261). Neither
   is on the guest list, and E/Space only take them (Loot).
   **Fix:**
   - Guest list: 653 and 654 as "use on a target", the host checking the
     target is 651 / 261 and in reach (like keys on doors), then running
     the script with the click answered.
   - Target System: a **Use** line for them in the item menu (and Space on
     one in the pack) brings up the crosshair, with E aiming at a spinning
     wheel or loom in reach.
   - `Friend_tool_for`: Space on a spinning wheel uses a bale from the
     pack, on a loom a spindle (as the firepit takes the sword blank), and
     allow it for guests too (today tools are host only).

9. **Bread: water, dough, baking.** The bucket (810, 0x32A) is already a
   guest tool and its script handles the dough (658): water on flour (dough
   frame 0) makes dough. Dough frames 1 and 2 (script 0x292) ask
   `click_on_item` and want the baking hearth (831), then bake bread after
   60 ticks. The dough isn't on the guest list. **Fix:** dough as "use on a
   target" wanting 831, with a Use line in the item menu and Space on the
   hearth using dough from the pack (`Friend_tool_for`). Then test the whole
   chain on a guest: fill the bucket at a well or trough, water the flour,
   bake.

3 and 10. **NPC state the guest never hears about.** Guests get NPC
   moves only for NPCs near the players (every 100 ms, tile and frame), and
   the story flags. Nothing sends an NPC's own flags or its removal:
   - 3: Exult names someone by `Actor::get_name`, which needs the NPC's
     *met* flag. The conversation sets it on the host only, so the guest
     keeps "peasant" until a new join brings the host's save.
   - 10: Weston freed: the host's script takes him out of the prison
     (removed or moved far away), so the host stops reporting him; the
     guest's copy stays where it last was.
   **Fix:** a new `npc_roster` blob from the host: for every NPC, its
   flags that guests show (met, dead, invisible, asleep, ...) and whether
   it is on the map, with its tile, sent whole on join and then only the
   NPCs that changed (checked twice a second). The guest sets the flags
   (names right at once), takes off its map NPCs the host has removed, and
   moves those the host moved out of the nearby list. Protocol version
   goes up.
